# ИИ-бот для Dune 2

Возможная команда: `computer_vision_engineer`, `game_state_engineer`, `policy_agent_engineer`, `test_engineer`. Разрабатывай в изолированной локальной игровой среде и отделяй адаптеры управления вводом от логики принятия решений.

## Сохранённый bootstrap-контракт

Архивированный placeholder `dune-rts` не являлся Git repository и не содержал продуктового кода. До появления отдельного репозитория действуют следующие ограничения:

- проект считается безустановочным, пока явно не принят технологический стек;
- автоматические уровни unit / integration / component пока не настроены;
- после появления кода временный минимальный gate выбирается по стеку (`cargo test` или `npm test`) и затем расширяется в порядке unit → integration → component;
- E2E определяется только после появления интеграционного backend/API;
- до этого момента E2E имеет явный blocker `BLOCKED_BY_BACKEND_DUNE_RTS`.

Исходный placeholder сохранён в migration backup, поэтому это объединение не уничтожает первичный контекст.
