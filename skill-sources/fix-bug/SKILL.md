---
name: fix-bug
description: Воспроизвести, локализовать, минимально исправить, протестировать и проверить конкретную программную ошибку.
---

1. Воспроизведи ошибку или создай детерминированный падающий тест.
2. Проверь соответствующую SPEC: ошибка находится в реализации, тесте или самом требовании.
3. Используй `explorer` для незнакомых путей; не запускай архитектора для локальной ошибки, если она не затрагивает границы компонентов.
4. До редактирования определи первопричину.
5. Назначь одного агента с правом записи на затронутую область.
6. По возможности добавь регрессионный тест, который падает до исправления и проходит после него.
7. Не меняй SPEC только для оправдания дефекта; обновляй её лишь при согласованном изменении ожидаемого поведения.
8. Запусти `reviewer` для исправлений, затрагивающих несколько модулей, данные, авторизацию, конкурентность или критичные production-функции.
9. Сообщи первопричину, затронутые требования, изменённые файлы, выполненные тесты и оставшийся риск.
