# Индекс спецификаций

- `system.spec.md` — общие границы и системные требования.
- `features/<feature>.spec.md` — требования отдельной существенной функции; создаются по мере необходимости.

| SPEC | Статус | Назначение |
|---|---|---|
| `system.spec.md` | Черновик | Базовая системная спецификация |

Используй устойчивые идентификаторы требований. Prompt этапа должен ссылаться на SPEC, а не дублировать её требования.
